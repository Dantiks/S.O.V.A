## 🎯 Функции виджета

### 4 типа виджетов:

#### 1. 💰 Общий баланс
- Показывает суммарный баланс всех счетов
- Обновляется автоматически каждый час

#### 2. 📉 Расходы за месяц
- Отображает общую сумму расходов текущего месяца
- Цветовая индикация (красный)

#### 3. 📈 Доходы за месяц
- Отображает общую сумму доходов текущего месяца
- Цветовая индикация (зелёный)

#### 4. 📊 Финансовая сводка
- Комбинированный виджет с балансом, доходами и расходами
- Компактное представление всех данных

## 🔧 Техническая реализация

### Используемые технологии:

1. **home_widget** (^0.4.1)
   - Пакет для создания виджетов на Android/iOS
   - Обмен данными между Flutter и нативным кодом

2. **SharedPreferences**
   - Хранение выбранного типа виджета
   - Кэширование данных

3. **Riverpod**
   - `widgetTypeProvider` - состояние выбранного типа

### Данные виджета:

```dart
await HomeWidget.saveWidgetData('widget_type', selectedType.name);
await HomeWidget.saveWidgetData('total_balance', totalBalance);
await HomeWidget.saveWidgetData('monthly_income', income);
await HomeWidget.saveWidgetData('monthly_expenses', expenses);
await HomeWidget.saveWidgetData('app_name', 'FINER');
```

### Обновление виджета:

```dart
await HomeWidget.updateWidget(
  name: 'FinerWidgetProvider',
  androidName: 'FinerWidgetProvider',
  iOSName: 'FinerWidget',
);
```

## 📱 Как установить виджет на устройстве

### Android:

1. **Добавление виджета:**
   - Долгое нажатие на пустую область рабочего стола
   - Выберите "Виджеты" в меню
   - Найдите виджет "FINER"
   - Перетащите на рабочий стол

2. **Выбор типа:**
   - Откройте приложение FINER
   - Перейдите в Настройки → Виджеты
   - Выберите нужный тип виджета
   - Нажмите "Обновить виджет"

### iOS:

1. **Добавление виджета:**
   - Долгое нажатие на рабочий стол
   - Нажмите "+" в левом верхнем углу
   - Найдите "FINER" в списке
   - Выберите размер и добавьте

2. **Настройка:**
   - Откройте приложение
   - Настройки → Виджеты
   - Выберите тип и обновите

## 📊 Данные виджета

### Общий баланс:
```dart
final totalBalance = accounts.fold<double>(
  0,
  (sum, account) => sum + account.balance,
);
```

### Доходы/Расходы за месяц:
```dart
final now = DateTime.now();
final startOfMonth = DateTime(now.year, now.month, 1);
final transactions = getByPeriod(startOfMonth, now);

final income = transactions
    .where((t) => t.type == TransactionType.income)
    .fold<double>(0, (sum, t) => sum + t.amount);

final expenses = transactions
    .where((t) => t.type == TransactionType.expense)
    .fold<double>(0, (sum, t) => sum + t.amount);
```

## ⚙️ Настройки в коде

### Провайдер типа виджета:
```dart
final widgetTypeProvider = StateProvider<WidgetType>(
  (ref) => WidgetType.balance
);

enum WidgetType {
  balance,
  expenses,
  income,
  chart,
}
```

### Загрузка настроек:
```dart
Future<void> _loadCurrentSettings() async {
  final type = await HomeWidget.getWidgetData<String>('widget_type');
  if (type != null && mounted) {
    ref.read(widgetTypeProvider.notifier).state = 
        WidgetType.values.firstWhere(
          (e) => e.name == type,
          orElse: () => WidgetType.balance,
        );
  }
}
```

## 🐛 Обработка ошибок

### Try-catch при обновлении:
```dart
try {
  // Сохранение и обновление данных
  await HomeWidget.updateWidget(...);
  
  // Уведомление об успехе
  ScaffoldMessenger.of(context).showSnackBar(
    const SnackBar(
      content: Text('Виджет обновлён'),
      backgroundColor: Colors.green,
    ),
  );
} catch (e) {
  // Уведомление об ошибке
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(
      content: Text('Ошибка: $e'),
      backgroundColor: Colors.red,
    ),
  );
}
```
